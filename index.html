About Me

Hello! I’m Noorul, a frontend developer passionate about building modern, high-quality digital experiences on the web.

My journey into web development began with experimenting on custom Tumblr themes, where I first discovered the power of HTML and CSS. What started as curiosity quickly grew into a strong interest in creating intuitive and visually appealing user interfaces.

Over time, I’ve worked on a range of projects that have helped me develop a solid foundation in modern frontend technologies and best practices. I focus on writing clean, maintainable code and building scalable applications that provide seamless user experiences.

Currently, I specialize in developing responsive, accessible, and performance-driven web applications using modern JavaScript frameworks and tools. I’m particularly interested in crafting user-centric products that balance design, functionality, and usability.
